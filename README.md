# I Wanna Be The Guy: Remastered Tribute Edition (Windows)

<img src="sce_sys/icon0.png" width="128" align="right">

Windows x64 build of *I Wanna Be The Guy: Remastered*, version 1.6.6.6, on a new GameMaker 8 runtime.

## Download (v1.6.6.6)
[IWBTGR-TributeEdition-win64.zip](https://github.com/kaizerfcm/iwbtg-remastered-tribute-edition-windows/releases/download/v1.6.6.6/IWBTGR-TributeEdition-win64.zip) ([latest release](https://github.com/kaizerfcm/iwbtg-remastered-tribute-edition-windows/releases/latest))

## Install
Windows 10/11 x64. Unzip anywhere and run `IWBTGR.exe`. Saves carry over between updates.

## What's in it
- Tribute mode, playable as the Tribute Kid
- Boss Rush modes once unlocked, each with its own best time
- File select with a picture of each save, New Game on empty slots
- 16 languages, with some Brazilian Portuguese voice acting
- Keyboard and controllers, remappable controls, fullscreen toggle

## Controls
| Keyboard (default) | Action |
| --- | --- |
| Arrows | Move |
| Shift | Jump |
| Z | Shoot |
| R | Restart |
| P | Pause |
| S | Skip |
| Backspace | Back |

Controls can be remapped in *Options*. F11 toggles fullscreen. Controllers work too.
